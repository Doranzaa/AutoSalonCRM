## Опис проєкту
**AutoSpace CRM** — це односторінковий вебзастосунок для керування автосалоном. Система дозволяє працювати з автомобілями, клієнтами, продажами, додатковими опціями, авторизацією користувачів і зверненнями через єдиний інтерфейс, реалізований на React, з бекендом на PHP та базою даних MySQL.

Застосунок побудований у форматі SPA, тобто перехід між сторінками відбувається без повного перезавантаження браузера, а дані надходять із API у форматі JSON.
## Мета проєкту
Мета проєкту — створити сучасну інформаційну систему для автосалону, яка дає можливість вести облік автомобілів, клієнтів, додаткових опцій, продажів і звернень користувачів в одному середовищі.

Окремою метою є демонстрація практичного використання React, React Router, Redux Toolkit, PHP API, MySQL, CRUD-операцій та розмежування прав доступу за ролями.
## Використані технології

|Категорія|Технологія|Призначення|
| :-: | :-: | :-: |
|Frontend|React|Побудова інтерфейсу та компонентів SPA.|
|Маршрутизація|React Router DOM|Перехід між сторінками без оновлення браузера.|
|Стан застосунку|Redux Toolkit|Зберігання авторизації та даних, отриманих із API.|
|Backend|PHP|Реалізація API для авторизації, CRUD та звернень.|
|База даних|MySQL|Зберігання всіх основних сутностей системи.|
|Обмін даними|Fetch API + JSON|Отримання та відправлення даних між frontend і backend.|
|Захист паролів|password\_hash, password\_verify|Безпечна реєстрація і перевірка паролів у PHP.|
## Функціональні можливості
Проєкт реалізує такі можливості:

- авторизація і реєстрація користувачів на одній сторінці;
- збереження сесії користувача після оновлення сторінки через localStorage;
- перегляд списку автомобілів із пошуком і фільтрацією;
- CRUD-операції для автомобілів, клієнтів, опцій і продажів;
- оформлення продажу з автоматичним підрахунком вартості;
- відправлення звернень авторизованим користувачем у базу даних;
- перегляд і видалення звернень адміністратором.
## Структура бази даних
У проєкті використовуються такі основні таблиці MySQL:

|Таблиця|Призначення|
| :-: | :-: |
|roles|Зберігає ролі користувачів (admin, user).|
|users|Зберігає логін, пароль, роль і токен користувача.|
|brands|Зберігає марки автомобілів.|
|cars|Зберігає інформацію про автомобілі.|
|clients|Зберігає дані про клієнтів.|
|options|Зберігає додаткові опції та їхню вартість.|
|sales|Зберігає інформацію про продажі.|
|inquiries|Зберігає звернення користувачів.|

Основні зв’язки між таблицями:

- users.role\_id -> roles.id;
- cars.brand\_id -> brands.id;
- sales.car\_id -> cars.id;
- sales.client\_id -> clients.id;
- inquiries.user\_id -> users.id.

### 1\. Головна сторінка
Головна сторінка є стартовою сторінкою системи. На ній розміщені основні кнопки навігації між розділами застосунку, а також блок із прикладами API-запитів, які можна перевірити через браузер або Postman.

На цій сторінці користувач одразу бачить, що система працює з API, а не зі статичними даними, оскільки відображаються приклади запитів до cars і clients.

## Ролі користувачів
У системі реалізовано три ролі користувачів:

- **guest** — неавторизований користувач, який може лише переглядати загальнодоступні сторінки;
- **user - логін | пароль: 123456** — авторизований користувач, який може надсилати звернення;
- `        `**admin - логін | пароль: 123456** — адміністратор, який має доступ до CRUD-операцій і керування зверненнями.
## Робота з API
Сайт підключений до PHP API, яке обробляє запити та повертає JSON-відповіді. Це можна продемонструвати через Postman або безпосередньо в браузері.

Приклади запитів:

GET http://localhost/autosalon/api.php?resource=cars\
GET http://localhost/autosalon/api.php?resource=clients\
POST http://localhost/autosalon/api.php?resource=auth&action=login\
POST http://localhost/autosalon/api.php?resource=auth&action=register\
POST http://localhost/autosalon/api.php?resource=inquiries\
GET http://localhost/autosalon/api.php?resource=inquiries

Наявність окремого API підтверджує, що frontend частина працює через запити до сервера, а не з локальними масивами чи мок-даними.
## Висновок
**AutoSpace CRM** — це повноцінний SPA-застосунок для автосалону, який поєднує frontend на React із backend на PHP і базою даних MySQL.

Проєкт реалізує авторизацію, реєстрацію, керування автомобілями, клієнтами, продажами, опціями та зверненнями користувачів, що робить його завершеним навчальним full-stack рішенням.
